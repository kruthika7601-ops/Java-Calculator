
# Java Calculator 🧮

My first Java programming project!

## About
A simple calculator developed using Java that performs basic arithmetic operations.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Division by zero handling
- Invalid operator handling

## Technologies Used
- Java
- JDK 27
- Visual Studio Code
- GitHub

## How to Run

1. Install Java JDK.
2. Open the project in VS Code.
3. Open the terminal.
4. Compile:

   javac Calculator.java

5. Run:

   java Calculator
